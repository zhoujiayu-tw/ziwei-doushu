# 使用流程：從輸入出生資料到每一頁

> 原型用的是算好的範例盤；正式版的起點是「使用者輸入出生資料」，所有東西從這一刻算出來。本文件定義這條路徑上每一頁放什麼、由哪個模組算、怎麼驗證。
> 使用者只有一人（本站不公開），但「雙人」功能需要兩份檔案，所以仍設計成多檔案。

## 0. 原則

1. **先算後畫**：一份出生資料進來，`lib/sky` 先算天文量，三個刻度層再切格，畫面只讀結果。沒有任何頁面依賴事先算好的表。
2. **一條時間軸**：每一頁都有同一個「時刻」控制；出生時刻是起點，「現在」是預設觀看點。
3. **寫明精度**：出生時間不確定、出生地沒有經度、年份超出曆表，都要在頁面上說，不能默默退化。
4. **全部在瀏覽器算**：出生資料存在本機（localStorage），不上伺服器；只有 AI 解讀把「出生資料」送到自己的 API，伺服器重排再丟給 Claude，不存。

## 1. 路徑總覽

```
/                 入口：有檔案 → 直接進「今日」；沒有 → 建檔
/new              建檔（出生資料表單）
/p/:id            這份檔案的首頁 = 今日（三把尺 + 天空）
/p/:id/natal      本命：天空（出生時刻）、四柱、命盤、本命星盤、格局
/p/:id/time       運：時間軸 ⇄ 日／月／年／十年
/p/:id/ask        AI 解讀（對話）
/p/:id/palette    配色（五行）
/pair/:a/:b       雙人：合盤 + 兩人今日
/settings         檔案管理、流派設定、匯出／匯入 JSON
```

導覽固定四個：**今日 · 本命 · 運 · 問**。雙人與設定放在檔案選單裡。

## 2. 建檔：出生資料表單

| 欄位 | 輸入 | 處理 |
|---|---|---|
| 稱呼 | 文字 | 只存本機 |
| 性別 | 男／女 | 紫微陰陽男女、大限方向 |
| 出生日期 | 國曆日期 | 1900–2100；超出曆表（lunar-javascript）直接拒絕並說明 |
| 出生時間 | 時：分；或勾「不確定」 | 見 §2.1 |
| 出生地 | 城市清單（`cities.ts`，含臺灣縣市）或手動經緯度 | 真太陽時、恆星時、上升點 |
| 時區／夏令時 | 自動：臺灣 1945–1979 夏令時表（A 階段補）、中國 1986–1991 | 顯示「已扣 1 小時」之類的說明 |

送出後**同一頁即時顯示**換算結果，讓人在存檔前確認：

- 真太陽時：`12:10 → 11:52（經度差 −6 分、均時差 −12 分）`，時辰 **午**。
- 若換算跨了時辰或跨日（晚子時），用一行紅字講清楚。
- 農曆、四柱、命宮身宮、五行局、命主身主、太陽／月亮／上升星座。

### 2.1 出生時間不確定

| 情況 | 做法 |
|---|---|
| 只知上午／下午／晚上 | 列出可能的時辰，各自算命宮，讓使用者看哪一個命宮主星「比較像自己」；存檔時記 `timeUncertain: true` |
| 完全不知道 | 紫微以午時起盤並全站標示「時辰未定」；八字只給年月日三柱；西洋不給上升、天頂，只給太陽月亮（月亮用正午） |

## 3. 今日（`/p/:id`）

這是日常打開看的頁，也是三把尺的主場。

| 區 | 內容 | 來源 |
|---|---|---|
| 天空 | 3D 空間切到「現在」：此刻的北斗、太陽、月亮；地盤上大限針、流年針、流月針 | `lib/sky` + `lib/ziwei` 運限 |
| 時刻列 | 今天的年月日柱、節氣區間、農曆、月相、太陽／月亮星座、水星順逆 | `lib/sky`、`lib/bazi` |
| 今日尺 | 日柱十神（對日主）一句話；月亮星座與本命點的相位（軌 3°）；紫微流日所在宮 | `lib/bazi`、`lib/astro`、`lib/ziwei` |
| 本月尺 | 節氣月柱十神；太陽與本命點相位（軌 6°）；流月宮 | 同上 |
| 今年尺 | 流年命宮落在本命哪一宮、流年四化；八字流年十神；木星土星行運 | 同上 |
| 七日表 | 未來七天的日柱、十神、月亮星座 | `lib/bazi`、`lib/sky` |
| 配色卡 | 今日宜／中／避三色與理由 | `lib/advice/palette` |

每個「一句話」旁都有「問 Claude」按鈕，把那一條帶進 `/ask`。

## 4. 本命（`/p/:id/natal`）

| 區 | 內容 |
|---|---|
| 出生時刻的天空 | 3D 空間：天球、紫微垣、北斗（點亮命主那顆）、南斗（點亮身主）、黃道上的太陽月亮、地盤 |
| 資料卡 | 國曆、農曆、真太陽時換算、四柱、五行局、命宮身宮、命主身主、陰陽男女 |
| 紫微命盤 | 十二宮方盤 + 盤心掛谷針；點宮看三方四正、星曜明細、大限 |
| 格局 | 引擎判定的格局，附《全書》出處 |
| 八字 | 四柱、十神、藏干、大運起運年與大運表 |
| 西洋本命 | 太陽、月亮、上升、天頂、各行星黃經與星座；本命相位表 |
| 一條線三把尺 | 把太陽黃經畫成一條 360° 的線：標出節氣、八字月、星座，使用者的太陽落在哪 |

## 5. 運（`/p/:id/time`）

時間軸可拖、可輸入日期、可按「出生」「現在」。四個尺度切換：

| 尺度 | 主尺 | 畫面 |
|---|---|---|
| 日 | 日柱十神 + 月亮星座 | 七日條 |
| 月 | 節氣月柱 + 太陽星座 | 一年十二格，標節氣時刻 |
| 年 | 紫微流年 + 八字流年 | 十二年一圈（太歲一周），標木星位置 |
| 十年 | 大限 + 大運 | 一生 120 年的針走過十二宮；外行星行運標在旁邊 |

每一格點下去，右側出現該時段的三把尺內容與「問 Claude」。

## 6. 問（`/p/:id/ask`）

- 現有 `/api/interpret`：把命盤重排後給 Claude，串流回答。
- 補上八字與西洋的事實（四柱十神、本命點、當前行運）進 system prompt，讓 Claude 可以跨系統回答；文案規則不變：只引逐字可查的原話。
- 常用問題按鈕依頁面帶入（今日、本月、這個大限、感情、事業）。

## 7. 雙人（`/pair/:a/:b`）

- 合盤：現有 `/api/heming`。
- 兩人今日：各自的日柱十神、相位，再給一句「兩人今日」（規則表：舊 app 的 `jointAdvice` 一般化成十神組合表）。
- 舊 app 的看板、檢核清單不搬進來。

## 8. 配色（`/p/:id/palette`）

- 個人喜忌：由八字五行分布算出，可手動覆寫（例如沿用舊 app 的結論）。
- 今日三色：規則見 unified-architecture.md §5；顯示色票、材質建議、一句理由。
- 站內開關：是否讓面板邊光跟著今日宜色微調。

## 9. 設定（`/settings`）

- 檔案：新增、改、刪；匯出／匯入 JSON（本機檔案，不上雲）。
- 流派：亮度流派、閏月口徑、晚子時策略（引擎已有 `school-config.ts`）。
- 顯示：繁體／簡體星名、是否顯示雜曜。

## 10. 資料與狀態

```ts
interface Profile {
  id: string; name: string; gender: 'male' | 'female';
  birth: { year, month, day, hour?, minute?, timeUncertain?: boolean };
  place: { name?: string; lon: number; lat: number; tz: string };
  overrides?: { favorableElements?: Element[]; brightnessSchool?: string };
  createdAt: string;
}
```

- 存 `localStorage['bz.profiles']`；要跨裝置再接 Cloudflare Access + KV。
- 每頁的計算結果不存，進頁即算（引擎單張盤 < 50 ms）。

## 11. 每一頁的驗證

| 頁 | 驗證 |
|---|---|
| 建檔換算 | 真太陽時對照引擎既有測試；時辰邊界回歸（`iztro-time-index-boundary`） |
| 本命 | 11 組引擎回歸 + 指紋；四柱取引擎 `fourPillars`；西洋 ASC/MC 對照已知案例 |
| 今日／運 | `lib/sky` 節氣時刻對照 lunar-javascript（< 0.02°）；流年命宮對照舊 app 的 2026–2033 表（它是用 iztro 算的，應完全一致） |
| 配色 | 純函數表格測試 |

## 12. 第一個可用版本（MVP）的範圍

1. 建檔表單 + 即時換算（§2）。
2. 本命頁：天空 + 資料卡 + 紫微命盤 + 四柱（§4，西洋先只給日月上升）。
3. 今日頁：時刻列 + 今日尺 + 本月尺 + 七日表（§3，西洋先只給日月相位）。
4. 問：沿用現有 API。
5. 其餘（運的四尺度、雙人、配色、設定）依序補。
