命盤是一個包含所有方向的集合

1917 年掛谷宗一問：一根針要在平面上轉遍所有方向，最少需要多大的地方？面積可以小到任意程度，維度卻永遠壓不下去。背後這片光，是三維空間裡每個方向各一根針；2025 年，王虹與 Joshua Zahl 證明了這樣的集合必然是滿三維的。紫微斗數也是一套「方向」的學問：十二宮、三方四正、大限流轉，一生會走過每個方向。

Chinese remainder theorem

六十甲子是一條 (6, 5) 環面紐結

十天干與十二地支各自循環，配對起來卻只有 60 組，不是 120 組：因為 gcd(10, 12) = 2，陽干只配陽支、陰干只配陰支。把天干當成環面的一圈、地支當成另一圈，六十甲子走完一輪，正好繞了 6 圈和 5 圈，首尾相接成一個紐結。

n ↦ (n mod 10, n mod 12)　// 循環群 ℤ₁₀ × ℤ₁₂ 中 (1,1) 生成的子群
週期 = lcm(10, 12) = 60　// 繞數 (60/10, 60/12) = (6, 5)

範例命盤的年、月、日、時四柱，在紐結上以亮點標出，數字是它在六十甲子裡的序號。

Cyclic group ℤ/12

三合是陪集，對宮是對合

十二地支就是 ℤ/12。子辰申 = {0, 4, 8} 是 4 生成的子群，另外三組三合都是它的陪集，四個三角形剛好就是水、金、火、木四局。對宮是 x ↦ x + 6，十二宮兩兩相對，連成六根穿過中心的針。三方四正就是「陪集 ∪ 對宮」。

三合(x) = x + ⟨4⟩ = {x, x+4, x+8}
對宮(x) = x + 6　// ℤ/12 中唯一的 2 階元素
大限：每 10 年走一宮，方向 ±1　// 陽男陰女順行，陰男陽女逆行

Besicovitch · Perron tree

同樣多的方向，擠進更小的面積

一個三角形切成 128 根細針，每根方向都不同。沿底邊把它們互相平移、交疊，方向一個都沒少，面積卻變小。Besicovitch 用這個辦法證明：讓針轉一圈的區域，面積可以小到任意程度。擠過頭，針尖反而散開，面積又變大。
