北斗是天上的一根針

面向正北抬頭，北極附近的星永遠不落，古人稱為紫微垣。北斗繞著北極轉，一天一圈；從北極指向搖光的這根「針」，掃過所有方向。掛谷問的正是：一根針要轉遍所有方向，最少需要多大的地方？

南斗六星是二十八宿的斗宿，位在人馬座，正對著銀河系中心。視線現在轉向它此刻的位置；如果它在地平線下，鏡頭會沉到地盤下方，讓你看見腳下的南斗。金色細線是太陽走的黃道。

Chinese remainder theorem

六十甲子是繞著你的 (6, 5) 紐結

十天干、十二地支各自循環，配起來只有 60 組，因為 gcd(10, 12) = 2：陽干只配陽支。把天干當成環的小圈、地支當成大圈，六十甲子走完一輪，正好繞 6 圈小圈、5 圈大圈，首尾相接成紐結。你的四柱是紐結上的四個亮點。

n ↦ (n mod 10, n mod 12)，週期 lcm(10, 12) = 60
// ℤ₁₀ × ℤ₁₂ 中 (1, 1) 生成的子群，繞數 (6, 5)

地盤：十二宮是地平圈的十二個方向

從頭頂往下看，地平圈依方位分成十二地支：子在北、午在南、卯東、酉西，就是命盤十二宮的位置（這裡以南方朝上，與傳統命盤一致）。三合是子群 ⟨4⟩ 的陪集，四個三角形是水、金、火、木四局；對宮 x ↦ x + 6 是穿過你的直徑。天上斗柄的方向，投影成地盤上那根金針。

Besicovitch · Perron tree

同樣多的方向，擠進更小的面積

一個三角形切成 128 根細針，每根方向都不同。沿底邊把它們互相平移、交疊，方向一個都沒少，面積卻變小。Besicovitch 用這個辦法證明：讓針轉一圈的區域，面積可以小到任意程度。擠過頭，針尖反而散開，面積又變大。
