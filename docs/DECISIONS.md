# 決定紀錄

格式：日期 · 決定 · 理由 · 影響。改方向前先看這裡。

## 2026-10-23

- **發展順序 B → A → C**：先補 AI 解讀後端（B），再臺灣在地化（A），最後引擎抽成套件（C）。理由：B 讓工具先能用。
- **部署在 Cloudflare Workers，不用 Vercel**：zhoujiayu.app 已在 Cloudflare；OpenNext 可跑 Next 16。影響：靜態快取靠 `populateCache`，`wrangler dev` 單獨跑會每次重渲染。
- **AI 用 Claude API，預設 `claude-opus-5-5`**，effort medium，開伺服器端備援模型；命盤在伺服器重排，前端只送出生資料。
- **非商業、個人使用**：倪師原話（CC BY-NC-SA）可以留；不做會員、付費。
- **介面直接做繁體**，不先簡體再轉。
- **網址 `bz.zhoujiayu.app`**；舊的 `ours.zhoujiayu.app/bazi` 功能併入本站，`ours` 保留家族樹與看板。
- **流量限制用 Workers Rate Limiting binding**（每 IP 6／分、全站 60／分），不用 WAF 規則。理由：跟程式碼走、可本機測。
- **iztro 升 2.6.3**：1,824 盤輸出相同；2.6.3 支援每盤各自設定。
- **只做深色**。
- **原型 v3 方向確認：以觀測者為中心的天、時、地、人立體空間**；v1（平面針）、v2（光場）作廢，只留 v3。
- **南北斗歸屬以《全書》為準，做成單一真源 `star-lineage.ts`**；排盤運算不讀它。理由：引擎安星用的是紫微系／天府系兩條鏈，與南北斗無關；南北斗只進解讀與視覺。
- **引擎指紋測試**：區分「改分類／文案」與「改排盤口徑」。
- **三套系統共用 `lib/sky`**：八字、紫微、西洋都是太陽黃經、月亮黃經、恆星時的量化；不再用寫死的 2026–2033 表。
- **先規劃 UX 流程再寫程式**：正式版從「輸入出生資料」開始，原型的範例盤只是設計依據。
- **repo 私有、站不公開**：fork 不能改私有，新建私有 repo `bz` 承接完整歷史；舊 fork 封存。
- **個人出生資料不進 repo、不上伺服器**（AI 解讀除外，且不儲存）。
